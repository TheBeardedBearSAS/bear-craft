# Gestion du contexte

La fenêtre de contexte est la ressource critique.

- Déléguer les investigations larges (> 3 fichiers) à des sous-agents ; ne lire que ce dont la tâche a besoin.
- `/clear` entre tâches non liées ; `/compact` de façon proactive au-delà de ~70 % de contexte.
- Plan Mode pour les changements de plus de 3 fichiers, l'architecture ou un impact incertain.
- Toujours fournir une boucle de vérification : tests, sortie attendue, capture d'écran.
