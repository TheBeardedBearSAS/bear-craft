# Kontextverwaltung

Das Kontextfenster ist die kritische Ressource.

- Breite Untersuchungen (> 3 Dateien) an Subagenten delegieren; nur lesen, was die Aufgabe braucht.
- `/clear` zwischen unabhängigen Aufgaben; `/compact` proaktiv ab ~70 % Kontext.
- Plan Mode für Änderungen an mehr als 3 Dateien, Architektur oder unklare Auswirkungen.
- Immer eine Verifikationsschleife bereitstellen: Tests, erwartete Ausgabe, Screenshot.
