# Paperclip-Coding-Standards (TypeScript)

Node 24.11+, TypeScript strict + `noUncheckedIndexedAccess`, pnpm 9.15+ Workspaces, Kebab-Case-Dateien, PascalCase-Typen, camelCase-Vars, kein `any`, strukturierte Logs mit Redaktion.
