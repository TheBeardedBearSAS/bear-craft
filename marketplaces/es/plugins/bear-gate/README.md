# Bear Craft — Gates

Quality gates: PRD, tech spec, backlog, sprint, story, alignment, commit, merge and release.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-gate@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.1.2.

## Commands

- `/bear-gate:check` — Ejecutar cualquier quality gate: documentales, de código (commit, merge, release) o checkpoint
