# Bear Craft — Team

Parallel multi-agent teams: audit, security review and sprint delivery.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-team@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.1.2.

## Commands

- `/bear-team:audit` — Equipo de Auditoría Completa - auditoría paralela multitecnología con subagentes
- `/bear-team:delivery` — Equipo de Entrega - ciclo completo del sprint (redacción + implementación) con subagentes
- `/bear-team:security` — Equipo de Revisión de Seguridad - auditoría de seguridad paralela multidimensión con subagentes
