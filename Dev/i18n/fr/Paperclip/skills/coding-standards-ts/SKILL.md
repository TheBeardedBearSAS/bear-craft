# Standards de code Paperclip (TypeScript)

Node 24.11+, TypeScript strict + `noUncheckedIndexedAccess`, workspaces pnpm 9.15+, fichiers en kebab-case, types en PascalCase, variables en camelCase, pas d'`any`, logs structurés avec redaction.

Voir ../../rules/03-coding-standards.md pour la documentation détaillée.
