# Documentation

Documentation as code, mise à jour dans la même PR que le changement.

- **Commentaires** : expliquer le POURQUOI (décisions non évidentes, contournements, références externes), jamais le QUOI.
- **README** : prérequis, installation, démarrage rapide, configuration, tests, déploiement.
- **API** : OpenAPI, avec erreurs (RFC 9457), authentification et exemples.
- **ADR** pour les décisions d'architecture importantes : statut, contexte, décision, alternatives, conséquences.
- **Changelog** : format Keep a Changelog.

Détails et templates : `.claude/references/base/documentation.md`
