# Dokumentation

Documentation as Code, im selben PR wie die Änderung aktualisiert.

- **Kommentare**: das WARUM erklären (nicht offensichtliche Entscheidungen, Workarounds, externe Referenzen), nie das WAS.
- **README**: Voraussetzungen, Installation, Schnellstart, Konfiguration, Tests, Deployment.
- **API**: OpenAPI, mit Fehlern (RFC 9457), Authentifizierung und Beispielen.
- **ADR** für wichtige Architekturentscheidungen: Status, Kontext, Entscheidung, Alternativen, Konsequenzen.
- **Changelog**: Format Keep a Changelog.

Details und Vorlagen: `.claude/references/base/documentation.md`
