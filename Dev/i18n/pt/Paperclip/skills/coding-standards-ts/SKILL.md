# Padroes de Codigo Paperclip (TypeScript)

Node 24.11+, TypeScript strict + `noUncheckedIndexedAccess`, workspaces pnpm 9.15+, arquivos kebab-case, tipos PascalCase, vars camelCase, sem `any`, logs estruturados com redacao.

Veja ../../rules/03-coding-standards.md para documentacao detalhada.
