# Gestão de contexto

A janela de contexto é o recurso crítico.

- Delegar investigações amplas (> 3 arquivos) a subagentes; ler apenas o que a tarefa precisa.
- `/clear` entre tarefas não relacionadas; `/compact` de forma proativa acima de ~70 % de contexto.
- Plan Mode para alterações em mais de 3 arquivos, arquitetura ou impacto incerto.
- Sempre fornecer um ciclo de verificação: testes, saída esperada, captura de tela.
