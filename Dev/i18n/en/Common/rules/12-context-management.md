# Context Management

The context window is the critical resource.

- Delegate broad investigations (> 3 files) to sub-agents; read only what the task needs.
- `/clear` between unrelated tasks; `/compact` proactively past ~70% context.
- Plan Mode for changes over 3 files, architecture or uncertain impact.
- Always provide a verification loop: tests, expected output, screenshot.
