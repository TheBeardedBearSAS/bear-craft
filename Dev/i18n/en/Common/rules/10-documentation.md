# Documentation

Documentation as code, updated in the same PR as the change.

- **Comments**: explain WHY (non-obvious decisions, workarounds, external refs), never WHAT.
- **README**: prerequisites, installation, quick start, configuration, tests, deployment.
- **API**: OpenAPI, with errors (RFC 9457), auth and examples.
- **ADR** for significant architecture decisions: status, context, decision, alternatives, consequences.
- **Changelog**: Keep a Changelog format.

Details and templates: `.claude/references/base/documentation.md`
