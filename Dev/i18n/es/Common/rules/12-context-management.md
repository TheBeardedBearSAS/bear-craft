# Gestión del contexto

La ventana de contexto es el recurso crítico.

- Delegar las investigaciones amplias (> 3 archivos) a subagentes; leer solo lo que la tarea necesita.
- `/clear` entre tareas no relacionadas; `/compact` de forma proactiva por encima de ~70 % de contexto.
- Plan Mode para cambios de más de 3 archivos, arquitectura o impacto incierto.
- Proporcionar siempre un bucle de verificación: tests, salida esperada, captura de pantalla.

Detalles (hooks, compactación, modelos, effort, worktrees): `.claude/references/base/context-management.md`
