# Documentación

Documentación como código, actualizada en la misma PR que el cambio.

- **Comentarios**: explicar el PORQUÉ (decisiones no evidentes, soluciones provisionales, referencias externas), nunca el QUÉ.
- **README**: requisitos previos, instalación, inicio rápido, configuración, tests, despliegue.
- **API**: OpenAPI, con errores (RFC 9457), autenticación y ejemplos.
- **ADR** para las decisiones de arquitectura importantes: estado, contexto, decisión, alternativas, consecuencias.
- **Changelog**: formato Keep a Changelog.

Detalles y plantillas: `.claude/references/base/documentation.md`
